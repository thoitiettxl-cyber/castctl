# module

This folder reserves the place for a future KernelSU module that
will run castctl on the user's rooted Android phone (KernelSU plus the
meta-hybrid_mount metamodule, with Magisk paths as a fallback).

The binary it ships is the linux_arm64 glibc 2.17 build, run through
the user's glibc module.

Planned only: no module code yet.

"Module" here means a KernelSU module. It is not a Go module, and
it is not a release target.
